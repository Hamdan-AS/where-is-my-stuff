# Repository cleanup and Git ignore rules

The repository contains the Django application, templates, active static assets,
migrations, automated tests, requirements, and documentation. `.gitignore` excludes
local credentials and files that can be generated or belong only to this machine.

| Files | Git handling | Cleanup |
| --- | --- | --- |
| `.env`, `.env.github`, other `.env.*` | Ignored | Keep locally; they contain configuration or credentials. |
| `.env.production.example` | Tracked | Keep; values are placeholders. |
| SQLite databases, `private-media/`, `.local-data/` | Ignored | Preserve; databases, uploads, backups, and archives may contain private data. |
| `.venv/`, `venv/` | Ignored | Keep for local development; reinstall dependencies if removed. |
| `__pycache__/`, `.pyc`, tool caches | Ignored | Safe to remove when the app is stopped; Python/tools recreate them. |
| `staticfiles/` | Ignored | Generated by `collectstatic`; recreate before serving production static files. |
| `*.log`, browser artifacts, coverage output | Ignored | Old output can be removed; keep active server logs while the process uses them. |
| `manual-test-images/`, `static/login-concepts/` | Ignored | Exploratory/generated fixtures; unnecessary for the current application. |
| `core/qa_tests/`, `report-qa/` verification documents | Tracked | Keep; they reproduce bugs and record the verified fixes. |

## Checking exclusions

From the repository root:

```powershell
git check-ignore .env .env.github db.sqlite3
git status --short
git ls-files
```

`.gitignore` prevents new untracked files from being added. It does not remove
already tracked files; `git rm --cached <path>` stops tracking a local file without
deleting it. Review `git diff --cached --name-status` before committing cleanup.

Git does not load `.env.github` automatically. Authentication must explicitly read
the token locally; never put it in a remote URL or commit it. A private repository
still excludes credentials, databases, and private uploads.
