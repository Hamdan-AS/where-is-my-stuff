Where Is My Stuff? local commands

Project folder:
/home/elite/sandbox/where-is-my-stuff-ui_iter

Local app URL:
http://127.0.0.1:8086/

Start the app (first time on a machine):
cd /home/elite/sandbox/where-is-my-stuff-ui_iter
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver 127.0.0.1:8086

Start the app (subsequent runs):
cd /home/elite/sandbox/where-is-my-stuff-ui_iter
source .venv/bin/activate
python manage.py runserver 127.0.0.1:8086

Open the Django admin:
http://127.0.0.1:8086/admin/

Create an admin user:
python manage.py createsuperuser

Run basic checks:
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py migrate --check

Run tests:
python manage.py test core

Use `core`, not `core.tests`. `core.tests` skips core/test_screening.py.

Optional real-browser tests, which need Playwright and Google Chrome:
pip install -r requirements-dev.txt
python manage.py test core.test_browser

Check what is using localhost ports:
ss -ltnp

Stop the Django dev server:
Press Ctrl+C in the terminal running runserver.

If the server is running in the background, find it:
ps -eo pid,ppid,stat,comm,args | grep 'manage.py runserver'

Then stop only that process:
kill <PID>

Notes:
- Use 127.0.0.1:8086 for this project.
- Do not stop Ollama, DNS, or printing services unless you are sure they belong to this app.
- Browser tests start their own temporary localhost server and need permission to bind it.
- db.sqlite3 holds full 13-digit CNICs and 16-digit card numbers in private answers.
  Keep it at mode 600 and do not commit it.
