## Run this copy on port 8088

There is no separate virtualenv here. `.venv` was not copied because its console
scripts hardcode the original path, so this copy runs on the original
interpreter, pointed at this directory:

```bash
/home/elite/sandbox/where-is-my-stuff-gps/.venv/bin/python manage.py runserver 127.0.0.1:8088
```
