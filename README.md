
# Where Is My Stuff?

A Karachi lost-and-found app that suggests possible matches between lost and found item reports.

## How it works

1. Create a Lost or Found report with the item’s details and location.
2. Answer private questions to help find matches.
3. Review suggestions and arrange a handover.
4. After both people agree, they can see each other’s contact details. Either person can mark the item returned after the meeting time.

Reports and personal items can have QR codes. Anyone scanning an active personal label can see its phone number.

## Privacy

A match or QR scan does not prove ownership. Private answers are hidden from other users and staff, but some ask for full CNIC or card numbers, which are stored without extra encryption. Photos are optional; their location metadata is removed.

## Status

The app is not launched for general public use. Password reset, profile editing, notifications, and in-app help are not available yet
